# ✨ 习惯小窝 — Habit Nest

> 一只可爱软萌的习惯打卡网页，纯 HTML + CSS + JavaScript，打开即用。

---

## 📖 简介

**习惯小窝** 是一个可爱风格的日常习惯打卡工具。你可以自由添加想要坚持的习惯（早睡、读书、运动……），每天打开页面，完成一项就点一下打勾，页面上会实时显示今日完成进度和连续坚持天数。

所有数据存储在浏览器的 `localStorage` 中，无需注册、无需服务器、无需网络。

---

## ✨ 功能特色

| 功能 | 说明 |
|------|------|
| 添加习惯 | 随时添加你想要坚持的习惯，最多 20 个 |
| 每日打卡 | 点击圆圈打勾完成，自动记录当天数据 |
| 进度条 | 实时显示今日完成比例和具体数量 |
| 连续天数 | 自动计算全部完成的连续天数 |
| 删除习惯 | 悬停显示删除按钮，可移除不再坚持的习惯 |
| 完成特效 | 打勾时星星飞溅，全部完成时彩色纸片飘落 |
| 小动物背景 | 9 只小动物头漂浮页面，会随机眨眼吐舌头 |
| 移动适配 | 完美适配手机屏幕 |

---

## 🚀 快速使用

1. 下载 `index.html` 文件
2. 用浏览器（Chrome / Edge / Safari）双击打开
3. 在底部输入框中添加习惯，比如"早睡"、"读书"
4. 每天完成一项就点一下右侧的圆圈打勾

也可以用本地服务器运行：

```bash
python -m http.server 8080
# 或者
npx http-server
```

## 💾 数据说明

所有数据保存在浏览器 `localStorage` 中（键名 `habit_tracker_data`）。清除浏览器缓存会丢失数据，如需导出可在开发者工具中复制相关内容。
